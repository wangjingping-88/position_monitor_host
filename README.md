# 倾角定位监测仪上位机

用于接收、解析和显示倾角定位监测终端的数据，并通过 MQTT 发送查询和设置命令。当前版本为 **v0.1.1**，采用 C# / .NET 8 / WPF，界面为中文，无第三方运行库或图表包依赖。

协议依据：[倾角定位监测仪通信协议 V0.1.1](docs/倾角定位监测仪通信协议.md)。

## 功能

- MQTT TCP / TLS 连接、账号认证、多主题订阅与断线重连。
- 网关、终端分层查看，支持列表序号、终端搜索及网关心跳动画。
- 常驻终端信息，以及倾角、GPS、电池分类显示、倾角趋势和采样记录。
- 上行报文分为网关交互报文和终端透传报文，支持原始数据、解析结果及缩进 JSON 查看。
- 查询终端信息和上报周期，设置周期、重启终端、设置功率与频点、设置加速度量程及远程唤醒。
- 下行发送预览、执行记录与报文详情；关联 MQTT 发布确认、网关反馈及终端响应。
- Windows 原生窗口按钮和阴影、应用图标和桌面快捷方式。
- GitHub Release 免认证检查更新、下载安装和启动失败自动回滚。

## 构建与运行

开发环境为 Windows 和 .NET 8 SDK。本项目的脚本将 SDK、缓存和临时目录配置到 `D:\Program Files`，具体安装与迁移方法见 [环境与构建](docs/环境与构建.md)。

```powershell
cd D:\code\position_monitor_host
# 构建并运行自动验证
.\scripts\Build.ps1
# 自包含发布，并创建桌面快捷方式
.\scripts\Publish.ps1 -DesktopShortcut
# 启动程序
.\启动.ps1
```

发布位置固定为 `publish\win-x64`，本机对应 `D:\code\position_monitor_host\publish\win-x64`。保留整个发布目录即可运行，自包含发布无需另外安装 .NET。构建产物和发布包不纳入 Git，首次克隆后需自行构建。

## MQTT 连接

1. 打开“连接设置”，填写服务器、端口、账号和密码。新连接默认服务器为 `117.172.29.2`，端口为 `36106`。
2. 在“订阅主题”中每行填写一个主题；公司前缀与网关 ID 可用于添加主题，`+` 表示全部网关。默认主题为 `ucchip/up/sgw/+/#`，QoS 1。
3. 点击“保存并连接”，全部主题订阅成功后显示“已订阅”。
4. 从左到右选择网关和所属终端，查看上行信息并操作右侧下行控制。

订阅两个指定网关的示例：

```text
ucchip/up/sgw/704154/#
ucchip/up/sgw/704155/#
```

最多支持 64 个订阅主题，支持 `+` / `#` 通配符，自动忽略空行与重复项。网关按实际收到的消息自动发现。连接使用 MQTT TCP / TLS；TLS 默认校验服务器证书。断线后自动重连并恢复全部订阅，点击“断开连接”可停止。

标准网关的下行主题根据所选目标自动生成，例如订阅 `ucchip/up/sgw/704154/#` 时，对应发布到 `ucchip/down/sgw/704154/[seq]`。主题和 JSON 保留协议原值。

连接配置保存在程序旁的 `data/connection.json`，升级发布保留配置。只有勾选“记住密码”才会将密码保存到当前 Windows 用户凭据管理器，配置 JSON 不含密码。运行配置、凭据和缓存不纳入 Git。

## 界面与下行控制

左侧为网关列表和终端列表，中间为上行信息，右侧为下行控制。列表卡片直接显示十进制 ID，鼠标悬停可查看十六进制；选中项使用绿色边框。终端信息卡副标题只显示采样数量，下行目标显示为“网关 704154 → 终端 51833”。

倾角、GPS 和电池分别展示，正常、异常、等待或未知状态使用绿色、红色、黄色。界面时间按北京时间展示；设备时间无效时，趋势使用消息接收时间。心跳只更新红心与计数，不刷入报文列表。

查询和设置响应显示在上行信息，执行结果更新到右侧记录；终端信息查询及周期响应会自动刷新对应字段。发送前可核对目标和 JSON 预览。控制命令不会自动重发；发布确认超时仍继续等待终端响应，业务超时后仍可在发送起 5 分钟内匹配迟到响应。

菜单栏“检查更新”通过公开 GitHub Release 获取正式版，无需 Token；支持下载进度、取消、SHA-256 校验、保留连接设置和启动失败自动回滚。v0.1.0 需手动换用 v0.1.1 便携包，后续可在线升级。发布方案见 [在线更新](docs/在线更新.md)。
