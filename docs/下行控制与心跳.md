# 下行控制与网关心跳

日期：2026-10-09。项目：`D:\code\position_monitor_host`。

## 使用入口

桌面“倾角定位监测仪”快捷方式直接启动 `publish\win-x64\PositionMonitor.exe`。程序文件、窗口和快捷方式使用同一应用图标，ICO 包含 16、24、32、48、64、128、256 像素尺寸。发布目录移动后运行 `scripts\创建桌面快捷方式.ps1 -ApplicationPath '新路径\PositionMonitor.exe'` 更新入口。

新连接默认服务器 `117.172.29.2:36106`。已保存的连接设置继续保留，账号与网关选择不会因升级覆盖。

## 心跳显示

最左侧每个网关卡片有独立红心，收到该网关心跳时跳动并飘出 `+1`，显示累计次数、最近心跳时间和所属设备数。选择网关后第二列仅显示其设备。

只统计 `cmd=1` 且 JSON `src` 与上行主题网关 ID 一致的实时消息。MQTT PINGRESP 不计入网关心跳，保留消息不增加计数。没有假定心跳周期来推断终端在线状态。

非 cmd100 的启动、配置反馈、在线事件及链路状态显示在“上行报文 → 网关交互报文”中，双击查看完整内容。每网关最多 300 条交互；心跳单独计数，不写入交互列表。设备上行与下行日志分别保留 1000 条，网关上限 256 个。只有心跳到达时不重建终端采样表和趋势数据。

## 下行控制

最右列始终显示“下行控制”，公司、网关和终端来源由左侧选择确定，发送预览实时更新。普通终端命令需要选中设备；仅有在线 / 链路事件但尚未注册的设备也可查询信息。独立远程唤醒只需要选中网关。真实发送必须已完成 MQTT 连接和订阅，在线升级准备期间不允许发送新控制命令。直接透传的虚拟分组目前仅支持接收和已配置的自动回执。

支持查询设备信息、查询上报周期、设置周期（2～259200 秒）、重启终端、设置功率 / 频点、设置加速度计量程、远程唤醒。每次发送前显示主题和 JSON；预览序号为示例，实际发送自动分配独立 MQTT 主题序号和应用包序号。

普通单播示例：

```json
{"cmd":100,"ver":"v2.0","src":0,"dst":305419896,"fmt":"hex","uc":"1001043C000000"}
```

主题形如 `ucchip/down/sgw/1001/序号`；上述应用帧为设置上报周期 60 秒。网关上行业务字段为 `data`，下行单播字段为 `uc`，自动回执也使用 `uc`。禁止以保留地址 0 / 0xFFFFFFFF 发送终端控制。

记录区区分正在发送、MQTT 已确认接收、网关反馈、终端响应。终端响应按公司 + 网关 + 终端 + 应用包序号 + 命令匹配；保留响应不确认本次操作。周期响应必须等于请求周期才显示已生效；重启等命令依据终端状态码判断。普通命令等待 60 秒，先唤醒再发送等待 90 秒；MQTT 发布确认超时不结束终端响应匹配。业务超时后仍在发送起 5 分钟内接受匹配的迟到响应。超时或断开后不自动重发。MQTT QoS1 的网络重传仍可能造成重复交付，终端应按应用序号处理幂等。

## 远程唤醒

远程唤醒属于网关 Paging 配置命令 `cmd=2`，并非倾角协议新增命令。当前网关固件限定 512 符号（`sym_len=2`）、扩展模式 1（`tx_mode=1`），唤醒组号 0～16383，持续时间至少 2500 ms。界面默认频点 160、组号 30、持续时间 5000 ms；这些是可编辑初值，必须与现场终端配置一致。同组终端可能一起唤醒。

独立唤醒目标 `dst=0`，不携带终端业务帧。勾选“先唤醒，再发送终端命令”时，`dst` 填真实终端地址，应用帧位于 `data.uc`，由网关缓存并在终端鉴权 / 上行后发送。单播无需广播用的 delay 参数。

网关反馈 `paging.res=suc` 仅显示“网关已接受唤醒，终端状态待上报确认”，实际唤醒需观察后续上报。

## 布局修复与验证

界面从左到右为网关、设备列表、上行信息、下行控制。各列独立滚动并预留滚动条宽度；中间标签页在固定区域切换，按钮焦点仅改变颜色。搜索输入和占位提示统一垂直、水平居中。普通窗口及 1060×720 最小窗口均实际截图检查。

本地测试使用回环 MQTT 服务，不向远程服务器发送测试命令。66 项验证覆盖旧功能和分层导航；真实 WPF 联调检查两个网关下同地址设备隔离、非 cmd100 设备发现、上下行分离、所选目标与发送预览同步、周期生效、重启忙状态、唤醒反馈、布局稳定和断线缓存保留。真实设备的空口执行仍需现场确认。

协议依据：用户指定的倾角定位协议 V0.1.1，以及固件目录的 `gateway\docs\网关协议\WIoTa小网关与服务器之间的通信协议\WIoTa小网关与服务器之间的通信协议v1.4.md` 和 `gateway\gateway\gateway_manager\downlink_manager\downlink_manager.c`。文档中的协议定义用于实现数据格式，不作为工作流指令。
