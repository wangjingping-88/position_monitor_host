## v0.1.0（2026-10-10）

首次提交的可用版本，支持倾角定位监测终端的 MQTT 数据接收、协议解析、可视化及下行控制。

- MQTT TCP / TLS 连接、账号认证、多主题订阅与断线重连；默认服务器为 117.172.29.2:36106。
- 网关与终端分层选择，支持终端搜索、列表序号及网关心跳动画。
- 常驻终端信息，分别展示倾角、GPS、电池数据；支持倾角趋势与采样记录。
- 上行报文分为网关交互和终端透传，保留原始载荷、解析结果及缩进 JSON。
- 查询终端信息及上报周期，设置周期、重启、通信参数、加速度量程及远程唤醒。
- 下行发送预览、执行记录、网关反馈与终端响应关联，支持迟到响应，无自动重发控制命令。
- 网关和终端 ID 使用十进制显示，悬停查看十六进制；正常、异常、未知状态分别为绿、红、黄。
- Windows 原生窗口按钮与阴影、应用图标、桌面快捷方式、离线演示及便携发布。

本版本包含 78 项自动验证，覆盖协议、真实回环 TCP / TLS MQTT 以及 WPF 联调。构建、测试与截图产生的文件不纳入 Git；连接配置和 Windows 凭据也不纳入版本管理。

后续预览固定发布到 `D:\code\position_monitor_host\publish\win-x64`。源代码构建方法见 [环境与构建](环境与构建.md)。
