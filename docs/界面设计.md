# 界面设计

日期：2026-10-09。面向倾角定位监测仪现场调试，按网关归属选择终端，直接对照上行数据与下行操作。

## 视觉约定

| 用途 | 色值 |
| --- | --- |
| 页面背景 | #F3F7F9 |
| 内容背景 | #FFFFFF |
| 正文 | #203842 |
| 有效状态与选中区域 | #087F78 |
| 次要文字 | #607780 |
| 分隔线 | #DBE5E9 |

每个网关的红心 #E64862 只在收到心跳时跳动；X/Y/Z 分别使用蓝 #2679C8、橙 #C47B14、紫 #8557BE，同时保留轴名。微软雅黑用于中文，Segoe UI 用于终端地址和测量值，标题 17～22、倾角 26、正文 12～13。参数与数值左对齐，搜索文字居中。

去掉系统标题栏里重复的小标题，保留大 logo、名称和操作说明。使用 64 像素高的一体顶部区域；右上角使用 Windows 原生的最小化、最大化 / 还原、关闭按钮，由系统确定位置及点击范围，最大化时可以直接在屏幕最右上角关闭窗口。启用原生 DWM 窗口边框与阴影，使普通窗口在白色背景下仍能看清边界。窗口名称保留为任务栏与辅助功能标识。业务菜单与上行信息面板左对齐，使用独立点击区域；最大化时按当前 DPI 收回不可见缩放边框占用，原生按钮区域保持透明，避免被 WPF 背景覆盖。

网关和设备导航使用窄列，中间测量区占据剩余宽度，最右侧操作列始终存在。默认窗口 1580×940，支持最小 1060×720；各列独立滚动，内容溢出时才出现 8 像素细滚动条，叠放于边缘，不挤占内容宽度。空列表和短详情没有无效滚动条占位；焦点边框不改变尺寸。中间与右侧标签页统一采用浅灰绿底、圆角按钮和青绿色选中状态。选中色只作用于标签文字，正文保持深色。

连接设置按行填写多个订阅主题；添加主题保留现有项，保存时去除空行及完全重复项。左侧最多显示前三个主题，更多主题用总数提示，悬停查看完整配置，避免订阅项过多挤压网关列表。主题不等于已发现网关，导航项以实际收到的消息为准。

上行区域的首项为常驻设备信息，位于三个标签页之外。版本、SNR、周期、配置和信息接收时间随消息刷新；无设备或仅有链路事件时显示未知值，切换设备不沿用旧信息。下方仅有实时数据、上行报文和采样记录三个标签页。实时数据按倾角信息、GPS 信息、电池信息分区；倾角仪与趋势在宽窗口并排，在窄窗口上下排列。GPS 独立显示经度、纬度、海拔和 HDOP，电池仅显示终端上报电压。

三类信息背景加深为倾角浅青绿 #E2F1EC、GPS 浅蓝 #E4EFFA、电池浅米黄 #F5EED9，使分区边界更清晰。趋势网格同步加深到 #C5DAD4；纵轴刻度按统一右边界对齐，正负号和不同位数不再造成刻度列参差。

设备信息背景为稍深的灰蓝 #E8EEF2。空数据提示放在标题后，显示“倾角趋势（接收有效采样后，三轴倾角将在这里绘制）”，图内不再重复提示；已有采样时隐藏括号提示。窄窗口允许标题自动换行。上行报文与采样记录的时间列统一名为“时间”，仍使用北京时间显示。

设备信息右侧采用与“等待采样”相同的 11 号、常规字重、灰色状态样式：未选设备显示“请选择设备”，收到注册或完整设备信息后显示“已注册”，仅有链路或采样消息时显示“待注册”。该位置不再显示设备地址。信息字段的标签和值均为 12 号字、垂直居中，保证同一行的文字基线一致。倾角仪无数据时保留刻度和坐标轴，去掉盘内“暂无倾角”文字。

网关与设备地址统一只显示十进制，悬停提示显示十六进制对照，例如 51833（0xCA79）或 1（0x1）。卡片不再保留十六进制的第二行，列表、设备归属、下行目标、交互摘要、解析详情及执行记录使用同一规则；搜索继续兼容十进制、十六进制及补零十六进制。

## 消息与选择关系

网关通过心跳、启动、配置或业务消息自动发现，身份为公司前缀与网关 ID。在线事件 cmd201 / 链路状态 cmd20 可发现终端，但不构造不存在的注册或采样。其他非 cmd100 内容保留在“上行报文 → 网关交互报文”中，双击打开完整详情；左侧仅为网关列表和订阅说明。

设备身份为公司 + 网关 + 终端地址。切换网关过滤设备；切换设备同步替换上行记录、最新测量、趋势、下行执行记录和预览。没有设备时使用明确空态，数值显示“—”，不显示之前选择的测量。

cmd100 应用帧的主动注册 / 上报，以及设置 / 查询响应都属于上行；人工命令、自动回执和网关发送反馈属于下行。命令结果仍在右侧汇总，上行响应留在中间以便核对。心跳只更新计数，不刷入原始消息表。

## 审查与验证

结构围绕“选择归属—观察数据—发送控制”的现场操作展开，没有增加无关统计卡片。倾斜仪承担测量示意，红心承担实时接收提示。下行直接在最右列操作，省去主界面与弹窗间切换；网关大报文通过双击查看，避免窄导航列承担全部调试内容。

实际 WPF 截图检查初始态、双网关回环消息、第二网关选择、上行报文、配置响应与最小窗口。联调验证两网关同地址终端的隔离、链路设备空态、上下行分离、目标与预览更新、按钮焦点坐标和标签页宽度稳定。

## 上行分类与记录区（2026-10-10）

上行报文增加“网关交互报文／终端透传报文”两个子页，网关交互不依赖选中设备，终端透传随设备筛选。移走左侧交互区后，网关列表占用整列剩余高度。两类报文的列表和详情按剩余空间分配高度，列表最少保留 88 DIP，防止嵌套页签和说明在最小窗口下挤掉表头与数据行。数据表格选中行使用 #087F78 和白色文字，通过单元格模板的 ContentPresenter 保证文字垂直居中。

下行表单最多占面板高度的 62%，内容超出时滚动；执行记录和下行报文利用其下方全部剩余高度。下行报文详情与列表通过分隔条调整比例。发送预览及上下行 JSON 均缩进展开，保留原始协议内容用于复核。

所有网关、设备和唤醒组号的展示使用同一 ID 格式；输入框保留十进制数值输入，悬停时显示十六进制换算。MQTT 字符串客户端 ID、订阅／发布主题与原始 JSON 不进行展示格式替换，避免复制后改变协议内容。
## 卡片序号、状态颜色与报文对齐（2026-10-10）

每个网关卡片右上角显示发现序号，从 1 开始；设备卡片显示在所属网关中的发现序号，也从 1 开始。序号在搜索、切换网关及断开连接后保持稳定。卡片第一行显示十进制地址与序号，鼠标悬停在地址上查看十六进制，不再因十六进制换行。

网关和设备的所有列表项均显示圆角底色卡片：未选中时使用浅灰青背景 #F1F6F7、边框 #DCE8EB；选中时使用浅绿背景 #E2F1EC 和主题绿色边框。悬停时边框加深，键盘焦点也使用主题绿色；所有状态保持相同的边框厚度、内边距与尺寸，切换选择不会移动内容。

四块信息卡片的右上角状态统一使用：正常青绿色 #087F78，异常红色 #C4473A，等待或未知黄色 #A87508。已注册为正常，待注册及未选设备为未知；倾角和 GPS 使用协议有效性判断；电池增加电压有效／电压无效／等待上报状态。注册／信息响应没有电压字段，按等待处理，不把缺少字段当作电池异常。电池上报的 0xFFFF 无效值显示红色。

两个报文子页统一为顶部 4 DIP 间距、34 DIP 表头、48 DIP 说明及复制栏，相同的列表／详情分配比例。横向滚动条只影响表格内部视口，不改变表头和详情区的位置。窄窗口保留至少 88 DIP 的表格高度，保证横向滚动条出现时仍能完整显示一行数据。

网关报文初始列宽为时间 100 DIP、消息 160 DIP、内容使用剩余宽度。终端报文为时间 100 DIP、消息使用剩余宽度、类型 160 DIP、结果 100 DIP；仍允许拖动列边界调整宽度和横向滚动查看内容。


## 终端命名与目标关系（2026-10-10）

主界面的设备列表与信息卡统一命名为“终端”“终端信息”，数量和空态提示也使用终端。网关及终端卡片的首行直接显示十进制数值，不加“网关”或“ID：”前缀；悬停仍显示十六进制对照。

终端信息卡副标题只显示采样条数，去掉重复的终端 ID。终端列表上方保留所属网关提示，便于辨认分组。下行目标以一行“网关 704154 → 终端 51833”显示，悬停可查看双方地址；无终端时提示“请选择终端”，无网关时提示“请选择网关”。实际命令路由仍随所选网关及终端更新。
