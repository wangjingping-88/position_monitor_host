# 上位机环境与构建

日期：2026-10-09。项目目录：`D:\code\position_monitor_host`。

## 已有环境

本机已有 `D:\Program Files\dotnet\dotnet.exe`，SDK 8.0.422 / 10.0.302 和 .NET 8 Windows Desktop 运行时。本次复用现有环境，无需新装 Python、Node、MQTT Broker 或图表库。

| 用途 | 路径 |
| --- | --- |
| .NET SDK / Runtime | `D:\Program Files\dotnet` |
| NuGet 包缓存 | `D:\Program Files\NuGetPackages` |
| NuGet HTTP 缓存 | `D:\Program Files\NuGet\http-cache` |
| CLI 用户工作目录 | `D:\Program Files\dotnet-home` |
| 构建临时目录 | `D:\Program Files\Temp` |

`scripts/Common.ps1` 在当前进程设置这些路径，不修改系统级环境变量。编译中间文件位于项目 `obj` / `bin`，发布包位于项目 `publish/win-x64`。

## 新电脑配置

1. 将微软 .NET 安装脚本或离线 SDK 下载到 `D:\Program Files\Installers`。
2. 安装 .NET 8 SDK 至 `D:\Program Files\dotnet`；若使用 `dotnet-install.ps1`，显式指定 `-Channel 8.0 -InstallDir 'D:\Program Files\dotnet'`。
3. 如需在开发构建模式运行 WPF，另安装 .NET 8 Windows Desktop Runtime 到同一目录，例如安装脚本 `-Runtime windowsdesktop -Channel 8.0 -InstallDir 'D:\Program Files\dotnet'`。只运行自包含发布包时无需此步骤。
4. 执行 `& 'D:\Program Files\dotnet\dotnet.exe' --list-sdks` 与 `--list-runtimes` 核对实际路径。

本次没有执行新的 SDK 安装。上述安装步骤为迁移指导。

## 桌面快捷方式与应用图标

运行 .\scripts\Publish.ps1 -DesktopShortcut 发布并创建当前用户桌面入口，或单独执行 .\scripts\创建桌面快捷方式.ps1。脚本通过 Windows SpecialFolders 查询桌面，兼容 OneDrive 重定向；快捷方式的目标、工作目录与图标均指向发布包。

图标源文件在 src\PositionMonitor.App\Assets，通过 ApplicationIcon 嵌入 EXE，同时作为 WPF 窗口资源。需要重新生成时运行 .\scripts\生成应用图标.ps1，仅使用系统 System.Drawing，不新增环境依赖。发布包换位置后重新创建快捷方式。

MQTT 新连接默认 117.172.29.2:36106；升级发布保留 data/connection.json 和已记住的凭据。
